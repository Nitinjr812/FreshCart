🛒 FreshCart
FreshCart is a modern grocery shopping UI built with React and CSS. It provides a clean, responsive, and user-friendly experience for browsing and managing grocery items.

🚀 Features
✅ Built with React – Fast and interactive UI
🎨 Styled with CSS – Simple and elegant design
📱 Responsive Layout – Works across all devices
⚡ Lightweight & Optimized – Smooth performance
